# 🇹🇭 Thailand Citizen Simulation Bot

บอท Discord จำลองชีวิตประชาชนในประเทศไทย พร้อมระบบเศรษฐกิจ, ตลาดหุ้น, และการท่องเที่ยว 77 จังหวัด

## 🌟 ฟีเจอร์หลัก (Features)

### 1. 💰 ระบบเศรษฐกิจ (Economy)
จำลองระบบการเงินเสมือนจริง แยกกระเป๋าตังค์ (Wallet) และธนาคาร (Bank)
- **หาเงิน**: คำสั่ง `/work` สุ่มอาชีพฮาๆ แบบไทยๆ
- **ธนาคาร**: ฝาก (`/deposit`) และถอน (`/withdraw`) เงินได้
- **โอนเงิน**: ส่งเงินให้เพื่อน (`/transfer`) หรือแจกเงิน (`/give_money`)
- **ร้านค้า**: ซื้อของต่างๆ (`/shop`)

### 2. 🗺️ ท่องเที่ยวทั่วไทย (Travel 77 Provinces)
ระบบจำลองการเดินทางและเช็คอินจังหวัดต่างๆ ครบทั้ง 77 จังหวัดทั่วประเทศไทย
- **Travel**: เดินทางไปยังจังหวัดต่างๆ (`/travel`) โดยสามารถเลือก **ยานพาหนะ** ได้ และมีระบบ **Cooldown 1 นาที** ระหว่างเที่ยว
- **Abroad Feature**: เมื่อไปต่างประเทศ ระบบจะให้กรอกชื่อประเทศ (รองรับทั้งไทย/อังกฤษ) และตรวจสอบข้อมูลจริงก่อนบันทึกลง Board พร้อมมอบ Role พิเศษให้อัตโนมัติ
- **Province Info**: ดูรูปภาพสถานที่ท่องเที่ยวสำคัญและรายชื่อคนที่อยู่ในจังหวัดนั้น (`/province`)
- **Check-in**: เช็คตำแหน่งปัจจุบันของตัวเอง (`/whereami`)
- **Population Dashboard**: ตารางสรุปจำนวนประชากรในแต่ละจังหวัดแบบ Real-time (`/setup_address`)
- *ข้อมูลจังหวัดและรูปภาพครบถ้วนสวยงาม*

### 3. <:sheild:1459451942819467388> ระบบยืนยันตัวตน (Roblox Verification)
ระบบยืนยันตัวตนและซิงค์ชื่อจาก Roblox
- **Setup**: แอดมินใช้คำสั่ง `/setup_verify [channel]` เพื่อส่งปุ่มยืนยันตัวตน
- **Verification**: ผู้ใช้กดปุ่มแล้วกรอกชื่อ Roblox บอทจะตรวจสอบและเปลี่ยนชื่อในดิสคอร์ดให้อัตโนมัติ

### 4. 🎫 ระบบรับยศด้วยปุ่ม (Reaction Roles)
มอบความสะดวกให้สมาชิกเลือกรับ Role เองผ่านปุ่มกดพร้อมอีโมจิ
- **Config**: แอดมินใช้ `/set_rolegiver` เพื่อเพิ่มหรือลบคู่ Emoji & Role ผ่าน UI
- **Setup**: แอดมินใช้ `/setup_rolegiver [channel]` เพื่อส่งกล่องรับยศที่ตั้งค่าไว้
- **Persistence**: ระบบทำงานตลอดเวลา สมูท และเป็นระเบียบ

### 5. 📈 ระบบตลาดหุ้น & คริปโต (Stock Market)
จำลองการเทรดสินทรัพย์เสมือนจริงแบบ Real-time พร้อมระบบเจ้าของหุ้น
- **Dashboard**: ปุ่มกดเข้าสู่พื้นที่ซื้อขาย และปุ่มตรวจสอบกระเป๋าหุ้น (ปุ่มเปลี่ยนสีและล็อคอัตโนมัติตามสถานะตลาด)
- **Multi-Step Trading**: ระบบซื้อขายแบบ 3 ขั้นตอน (เลือกหุ้น -> เลือกประเภท -> ระบุจำนวน) ทันสมัยและใช้งานง่าย
- **Trade Validation**: ปุ่ม **"ยืนยันรายการ"** จะถูกล็อคไว้จนกว่าจะกรอกข้อมูลครบถ้วน เพื่อป้องกันความผิดพลาด
- **Stock Ownership**: ผู้เล่นสามารถเป็น "เจ้าของหุ้น" ได้ (สร้างหุ้นเอง) และตั้งราคาได้
- **P2P Trading (Bank)**: 
    - คนมาซื้อหุ้น -> เงินโอนเข้า **ธนาคารเจ้าของหุ้น**
    - คนมาขายหุ้น -> ดึงเงินจาก **ธนาคารเจ้าของหุ้น** คืนให้คนขาย
- **Interactive Management**: ระบบจัดการหุ้นสำหรับแอดมินผ่าน Modal และ UI โต้ตอบทั้งหมด

## 🛠️ การติดตั้ง (Installation)

1. **Clone Project**
   ```bash
   git clone https://github.com/yourusername/thailand-bot.git
   cd thailand-bot
   ```

2. **ลง Library ที่จำเป็น**
   ```bash
   pip install discord.py python-dotenv
   ```

3. **ตั้งค่า .env**
   สร้างไฟล์ `.env` และใส่ Token ของบอท:
   ```env
   DISCORD_TOKEN=your_token_here
   ```

4. **รันบอท**
   ```bash
   python main.py
   ```

## 👮 Admin Commands (สำหรับแอดมินหรือผู้ดูแลหุ้น)

### 💰 Economy Admin
- `/add_money [target] [amount]`: เสกเงินให้ผู้ใช้

### 📈 Crypto Admin
- `/admin_crypto [action]`: จัดการรายชื่อผู้ที่มีสิทธิ์ดูแลระบบหุ้น (Add/Remove/List)
- `/setup_crypto`: สร้างกระดานเทรด (ลบอันเก่าให้อัตโนมัติ)
- `/set_crypto`: เมนูโต้ตอบสำหรับ **เพิ่ม/แก้ไข/ลบ** หุ้นในตลาด (เลือกเจ้าของได้)
- `/set_crypto_perm [open/close]`: เปิด หรือ ปิด ตลาด
- `/update_crypto`: บังคับอัปเดตราคาบนหน้าบอร์ด

## 📂 โครงสร้างโปรเจค (Project Structure)
- `main.py`: ไฟล์หลักสำหรับรันบอท
- `cogs/`: โฟลเดอร์เก็บโค้ดระบบต่างๆ
  - `economy.py`: ระบบการเงินและธนาคาร
  - `crypto.py`: ระบบหุ้นและ P2P Trading
  - `thailand.py`: ระบบการเดินทางและข้อมูลจังหวัด
  - `serverstats.py`: ระบบแสดงสถิติเซิร์ฟเวอร์แบบ Real-time
- `json/`: โฟลเดอร์เก็บข้อมูลฐานข้อมูล (สร้างอัตโนมัติ)
  - `crypto_data.json`: ข้อมูลการตลาดและพอร์ตหุ้น
  - `economy_data.json`: ยอดเงินฝากและกระเป๋าตังค์
  - `server_stats.json`: ข้อมูลช่องทางสถิติ
  - `provinces.json`: ข้อมูลจังหวัด 77 จังหวัด
  - `user_locations.json`: ตำแหน่งปัจจุบันของผู้เล่น


## การนำไปใช้งาน (Deployment)

ไฟล์ที่ถูกเพิ่มเข้ามาเพื่อรองรับการนำไปใช้งานบนเซิร์ฟเวอร์หรือคลาวด์:

1.  **Dockerfile**: สำหรับสร้าง Container เพื่อรันบอทในสภาพแวดล้อมที่เสถียร
2.  **Procfile**: สำหรับใช้งานบน Heroku, Render หรือ Railway
3.  **.dockerignore**: เพื่อไม่ให้ไฟล์ที่ไม่จำเป็น (เช่น `.env` หรือ cache) ถูกรวมเข้าไปใน image
4.  **.gitignore**: เพื่อป้องกันการอัปโหลดไฟล์ความลับไปยัง Git

### วิธีการรันด้วย Docker
```bash
# สร้าง Image
docker build -t thailand-bot .

# รัน Container
docker run -d --env-file .env thailand-bot
```

### การตั้งค่าบน Cloud (Heroku, Render, Railway)
- เชื่อมต่อ GitHub Repository
- ตั้งค่า Environment Variables (Config Vars) ในหน้าเว็บของ Platform นั้นๆ:
    - `DISCORD_TOKEN`: โทเคนของบอท
- เลือก Start Command เป็น `worker: python main.py` (ระบบจะอ่านจาก Procfile อัตโนมัติ)
